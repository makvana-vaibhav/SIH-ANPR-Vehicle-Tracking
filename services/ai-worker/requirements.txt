# ── RapidOCR, installed --no-deps ──────────────────────────────────
# It declares a dependency on `opencv-python`, the full build, which drags in
# libGL and every other X11 library a server has no business carrying. Both
# builds provide the `cv2` module, so whichever pip installs last wins — and
# the loser is silently displaced. That is how a headless image ends up
# crashing on `libGL.so.1: cannot open shared object file`.
#
# So RapidOCR is installed with --no-deps in the Dockerfile and its real
# dependencies are pinned here, minus the OpenCV it should not choose for us.
